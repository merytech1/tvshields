## Fullscreen video

- Press OK on a web player's fullscreen button to expand the video. Press Back to return to the same page.
- The remote cursor reaches controls at the right and bottom edges of the page.

## Download and update

Use `tvshields-v0.1.1-universal.apk` if you are unsure which version your device needs.
The `armeabi-v7a` and `arm64-v8a` APKs are smaller downloads for 32-bit and 64-bit devices,
respectively.

Install the APK over v0.1.0 to update. With Downloader, use the
[latest universal APK](https://github.com/merytech1/tvshields/releases/latest/download/tvshields.apk).
With ADB, run `adb install -r tvshields-v0.1.1-universal.apk`.

`SHA256SUMS` lists the checksum of each APK. To verify the signing certificate, use the fingerprint
in the [v0.1.0 release notes](https://github.com/merytech1/tvshields/releases/tag/v0.1.0#checking-the-download).
