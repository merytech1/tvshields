First release of tvshields: a lightweight browser for Android TV that blocks ads and trackers in
the style of Brave's Shields, used with the TV remote.

## What it does

- **Network blocking** with Brave's [`adblock-rust`](https://github.com/brave/adblock-rust) and
  filter lists (uBlock Origin, EasyList, EasyPrivacy, Brave). Lists are downloaded on the first
  launch and kept up to date; they are not inside the APK.
- **Cosmetic filtering**: hides the empty spaces and banners that blocked ads leave behind.
- **Script replacement**: scriptlets and harmless stand-in resources (including Brave's SugarCoat)
  for scripts that detect blockers or track.
- **Per-site Shields**: on by default, can be turned off for one site, with a counter of blocked
  items.
- **Search**: Brave Search by default; DuckDuckGo, Startpage or Google in Settings.

## Which file to download

| File | For |
|---|---|
| `tvshields-v0.1.0-universal.apk` | Any device. Use it if you are not sure. |
| `tvshields-v0.1.0-armeabi-v7a.apk` | 32-bit devices: most Android TVs and TV boxes. Smaller. |
| `tvshields-v0.1.0-arm64-v8a.apk` | 64-bit devices. Smaller. |

`adb shell getprop ro.product.cpu.abilist` shows what a device supports: if `arm64-v8a` is not in
the list, take `armeabi-v7a`.

The release also includes `tvshields.apk`, a copy of the universal APK under a fixed name. With the
**Downloader** app, use
`https://github.com/merytech1/tvshields/releases/latest/download/tvshields.apk`: it always downloads
the latest version.

Needs Android 7.0 or later (Android TV, Google TV, Fire TV, Android boxes). Install it from a USB
drive with a file manager, with a downloader app, or with
`adb install tvshields-v0.1.0-universal.apk`. The device must allow installing apps from that
source.

## Checking the download

`SHA256SUMS` lists the checksum of each APK. The APKs are signed with the tvshields release
certificate, SHA-256
`a5:06:fa:b3:36:7c:d9:71:bb:55:93:f7:74:27:2c:0e:51:1b:3c:04:f9:7d:7f:c0:17:7c:45:81:60:d9:4e:67`
(`apksigner verify --print-certs <apk>`).
